# Data Analytics, BI and Decision Systems Portfolio

Hi, I'm **Kevin Odhiambo Otieno**, a Data and Business Intelligence Analyst based in Nairobi, Kenya.

I build analytics solutions from raw data all the way to the decision it supports. Most of my work goes beyond static reporting. I combine SQL data modeling, Python pipelines, Power BI dashboards and agentic AI workflows to tackle real P&L and operational problems.

## Project Structure

Every project in this repo uses the same folder layout.

````text
0X-Project-Name/
├── dataset/      # Raw and cleaned datasets, plus a data dictionary
├── sql/          # Schema design, views, CTEs and analytical queries
├── python/       # ETL pipelines, predictive models and agentic workflows
├── bi-app/       # Power BI (.pbix) files, DAX measures or Streamlit apps
├── images/       # Dashboard and app screenshots
└── README.md     # Business problem, architecture, key metrics and insights
````
